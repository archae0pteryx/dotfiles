# Agent instructions

## Code review

No CodeRabbit on this repository, at all.

- Don't run it: no `coderabbit` CLI, no `coderabbit review`, no `@coderabbitai`
  commands in PR comments.
- Don't request or re-trigger its reviews. `.coderabbit.yaml` exists only to
  switch it off; don't loosen it.
- If it comments on a PR anyway, ignore it: don't apply its suggestions, reply
  to it, or treat its findings as review feedback.
